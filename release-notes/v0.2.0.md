# Relux Proxy v0.2.0

Relux Proxy v0.2.0 adds saved, independently controlled SSH SOCKS profiles to
the native macOS menu-bar app.

## Highlights

- Save multiple profiles with stable identity and a unique local port.
- Connect multiple profiles at once as concurrent local SOCKS endpoints on
  `127.0.0.1`.
- Use an IP address, DNS hostname, or SSH config alias without Relux Proxy
  parsing or rewriting `~/.ssh/config`.
- Leave Account empty to preserve the `User` selected by OpenSSH for a matching
  SSH config alias, or set Account to pass an explicit `-l` user override.
- Start, stop, diagnose, edit, and remove profiles independently. A failed or
  occupied port affects only that profile.
- Migrate the previous single-tunnel preferences once while retaining the old
  keys for rollback compatibility.

Relux Proxy continues to launch the system `/usr/bin/ssh` client. Each endpoint
is an application SOCKS5 proxy for TCP traffic, not a system VPN. SOCKS-aware
clients should enable SOCKS5h or proxy DNS when the remote SSH host must resolve
private names.
