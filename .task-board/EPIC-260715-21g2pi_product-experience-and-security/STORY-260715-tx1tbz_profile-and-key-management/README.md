# Cross-platform profile and private-key management

## Description
Deliver production profile CRUD and SSH public-key credential management for the iOS and macOS containing apps while preserving a least-privilege app-to-extension boundary. The containing apps own user edits; packet-tunnel providers consume immutable non-secret profile generations and resolve credentials only through opaque Keychain references.

## Scope
In scope: profile list, create, edit, validation, selection, deletion, display name, canonical host or address, SSH port, account, private-key selection, optional passphrase handling, key import, key generation, explicit export, App Group publication, Data Protection Keychain storage, shared app/extension access-group boundaries, iOS and macOS presentation, accessibility identifiers, unit/integration/UI tests, and cleanup semantics. Out of scope: password-only SSH, agent forwarding, arbitrary shell sessions, OpenSSH config import, ProxyJump, public SOCKS configuration, host-trust confirmation UI, live VPN controls, and legacy SOCKS migration policy.

## Acceptance Criteria
1. On iOS and macOS a user can create, validate, edit, select, and delete profiles containing display name, canonical hostname or address, SSH port, account, and a private-key reference, with field-specific accessible errors. 2. App Group storage contains only versioned non-secret profile snapshots and opaque Keychain references, is published atomically, and never contains raw keys or passphrases. 3. Imported and generated keys use the approved formats and platform cryptography, live in the minimum Data Protection Keychain access group, and are never exported without an explicit user action. 4. Deletion and replacement preserve referential integrity, handle active-profile conflicts explicitly, and remove secrets only when no retained profile references them. 5. The M1 profile loader and extension Keychain resolver consume a published generation without secrets in providerConfiguration, logs, diagnostics, or board artifacts. 6. Swift tests plus iOS and macOS UI tests cover valid and invalid profiles, import, generation, protected keys, selection, deletion, relaunch persistence, accessibility, and screenshot review.
