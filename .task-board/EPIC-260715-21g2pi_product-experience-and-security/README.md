# M4 — Product experience and security

## Description
Deliver production profile, key, trust, status, diagnostics, privacy, onboarding, and accessibility experiences for iOS and macOS.

## Scope
Profiles, Keychain keys, host trust, VPN controls/status, onboarding, settings, diagnostics, privacy disclosure, support export, accessibility, and current SOCKS migration decisions.

## Acceptance Criteria
A user can configure, trust, connect, understand capability/failure state, and disconnect on iOS and macOS; credentials and diagnostics meet the threat model; accessibility and privacy acceptance tests pass.
