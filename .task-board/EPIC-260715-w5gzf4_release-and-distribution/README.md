# M5 — Release and distribution

## Description
Deliver tested macOS and iOS release pipelines, relay supply-chain controls, compliance evidence, and App Review materials.

## Scope
Cross-platform CI, relay supply chain, macOS Developer ID/notarization, iOS signing/TestFlight, SBOM/notices, stable artifacts, release operations, privacy/legal, and App Review submission.

## Acceptance Criteria
Signed release candidates install through intended channels; entitlement/signature/notarization/TestFlight gates pass; relay assets are reproducible and verified; review/privacy/legal packages match actual behavior.
