# Signed, notarized, and recoverable macOS distribution

## Description
Deliver a protected macOS release path for ReluxProxyMac and its packet-tunnel extension, including archive assembly, minimum entitlements, nested signing, hardened runtime, notarization, stapling, Gatekeeper validation, DMG publication, stable authenticated assets, migration checks, and rollback.

## Scope
In scope: release signing contract, Developer ID credentials and least-privilege ownership, host and extension identifiers, provisioning and entitlements, relay and notice embedding, version propagation, release archive, inside-out nested signing, hardened runtime, signature inspection, notarization, stapling, Gatekeeper assessment, deterministic DMG assembly where signing permits, checksums and provenance, versioned and stable ReluxProxy.dmg assets on a private GitHub repository, authenticated retrieval, clean install, upgrade, legacy-product migration or coexistence, rollback, revocation, and release evidence. Out of scope: iOS signing, TestFlight, product feature implementation, changing the approved bundle or migration decision, weakening entitlements to satisfy signing, public unauthenticated private-repository assets, and storing certificates or keys in the repository or board.

## Acceptance Criteria
1. The release archive contains the approved macOS host and exactly one embedded tunnel extension, bundled relay assets and notices, and exact bundle, App Group, Keychain, packet-tunnel, deployment-target, and version metadata. 2. Every nested executable is signed inside-out with the intended Developer ID identity, compatible profiles and minimum entitlements, hardened runtime, timestamps, and a passing strict signature assessment. 3. The distributed DMG is notarized, stapled, accepted by Gatekeeper on a clean supported Apple-silicon Mac, and accompanied by verified checksums, SBOM or notice links, source and relay provenance, and version metadata. 4. Private-repository publication exposes immutable versioned assets plus the stable ReluxProxy.dmg name through authenticated GitHub access, updates the stable asset without a partial window, and proves unauthenticated access is not assumed. 5. Clean install, upgrade from the supported legacy release, approved coexistence or migration, extension approval, connect or disconnect smoke, uninstall, previous-version rollback, bad-release withdrawal, and credential revocation are reproducible. 6. Production credentials are environment-scoped, masked, rotation-tested, absent from forks and retained artifacts, and release jobs are serialized with an auditable evidence bundle.
