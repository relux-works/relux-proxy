# M0 — Viability and foundation

## Description
Resolve Apple platform viability and prove the packet, memory, SSH, and project foundations that all product work depends on.

## Scope
Apple packet-tunnel intended-use evidence, Relux Works capabilities, multi-target project plan, public packet bridge spike, HEV constraints, and SSH-engine selection. No production feature work is accepted before its gates pass.

## Acceptance Criteria
Gate A0 has documented evidence; Gate P0 installs a packet-tunnel provider on physical iPhone and Mac; packet bridge/HEV and one SSH engine pass the M0 matrix; open decisions are recorded with reproducible results.
